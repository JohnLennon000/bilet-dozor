# Дозор билетов — разбор неполадок

## РЖД: «Нет связи с источником (таймаут)»

1. Найти последний запуск (`mcp__github__actions_list`, `check.yml`) → `list_workflow_jobs` → `get_job_logs`.
2. Шаг «Пустить интернет через телефон»:
   - `устройство: Redmi Note 7 | в сети: нет` — телефон не подключён к Tailscale. Попросить пользователя на Redmi Note 7:
     интернет есть (сайт открывается; 5 ГГц Wi-Fi уже отваливался — на 2.4 ГГц стабильнее) → Tailscale включён (Connected) →
     Exit node → «Run as exit node». MIUI: Приложения → Tailscale → Контроль активности «Нет ограничений», Автозапуск;
     держать на зарядке. Консоль: https://login.tailscale.com/admin/machines — зелёная точка.
   - `выход разрешён: нет` — в консоли Tailscale у телефона ⋯ → Edit route settings → Use as exit node.
   - Устройства нет в списке — телефон вышел из аккаунта (очистка данных приложения) → войти заново через GitHub; появится новая запись (например `redmi-note-7-2`), её разрешить как exit node, старую удалить.
   - `Страна выхода: RU`, а таймаут остаётся — РЖД мог ограничить адрес: пусть переключит телефон на другую сеть / перезагрузит роутер / режим полёта на мобильном.
3. После исправления — запуск с `{"probe": true}` и чтение `docs/data/probe.json`.

## Телефон засыпает (MIUI 12.5.1, Android 10, Redmi Note 7)

Пользователь 6 ноября включил всё это; если телефон снова выпадает по ночам — пройтись по списку ещё раз:
1. Подключение и общий доступ → VPN → ⚙ Tailscale → «Постоянная VPN» (без «Блокировать подключения без VPN»).
2. Недавние приложения → зажать карточку Tailscale → замочек.
3. Батарея и производительность → ⚙ → «Очищать кэш при блокировке» — Никогда; «Отключать мобильный интернет при блокировке» — выкл.
4. Приложения → Tailscale: Автозапуск вкл, Контроль активности «Нет ограничений», Другие разрешения — запуск в фоне.
5. Wi-Fi в спящем режиме — всегда; держать на зарядке; Wi-Fi 2.4 ГГц (5 ГГц отваливался).

## РЖД: формат ответа (`schema`)

`python -m dozor probe --raw tests/fixtures` (на машине с российским адресом) или probe в Actions → «Фрагмент ответа» в `docs/data/probe.json`. Править `parse_train_pricing` / `parse_suggestions` в `dozor/sources/rzd.py`, класть настоящие ответы в `tests/fixtures/` и писать тест. Известно: поезд «из расписания» приходит с `"CarGroups": []` и `IsFromSchedule: true` — это «мест нет», а не ошибка. Группа вагонов может прийти как «КУПЕ» (верхний регистр) — `CAR_TYPES` её не переводит.

## Станция не найдена

Probe пишет кандидатов из подсказок РЖД. Указать код вручную: `from_code` / `to_code` (цифры) в блоке поезда `config.yaml`. Известные коды: Туймазы 2024750, Москва (все вокзалы) 2000000, Уруссу 2024722.

## Будильник cron-job.org

История задания: console.cron-job.org → задание «Дозор билетов» → История → строка → подробности.
- `401` — заголовок `Authorization` (ровно `Bearer github_pat_…`, без кавычек и лишних пробелов; переключатель «Требует HTTP аутентификации» выключен) или истёк токен.
- `403/404` — токен без доступа к `bilet-dozor` или без права Actions: Read and write.
- `422` — опечатка в теле запроса.
- `500/502/503` — сбой GitHub, единичный — не страшно.
- Два одинаковых задания — удалить лишнее (иначе запуски парами и двойная нагрузка на РЖД).

Сверка: новые запуски `workflow_dispatch` в GitHub примерно каждые 10 минут; шаг «Проверить билеты» должен идти как `python -m dozor` без `--force`.

## Push-уведомления

- Подписки — файлы `push/<id>.json` (создаёт пользователь кнопкой в приложении → GitHub → Commit changes). Сводка: `summary.json → push.devices`.
- Ответ push-службы 404/410 — подписка умерла, сервис удаляет файл сам; пользователю переподключить в приложении.
- 403 «VAPID credentials … do not correspond» — ключ сменился (менялся `TRAVELPAYOUTS_TOKEN`/`PUSH_SECRET`): переподключить уведомления.
- Установка PWA на Android — кнопкой «Установить» на самом сайте; iPhone — Safari → Поделиться → На экран «Домой», iOS 16.4+.

## Запуск упал на «Сохранить данные»

Причина в прошлом — два запуска на одном коммите и конфликт в `docs/data/*.json`/`state/state.json`. Исправлено: checkout с `ref: ${{ github.ref_name }}` и `git rebase -X theirs`. Если повторилось — читать журнал шага, не удалять `concurrency`.
