# Дозор билетов скилл

Пользователь говорит по-русски и работает **только с Android-телефона**: отвечать по-русски, коротко, шагами, которые можно сделать на телефоне. Перед любыми действиями на его устройствах — сначала сказать, что собираетесь делать. Токены и ключи в чат не просить.

Подробная история и правила кода — в `CLAUDE.md` репозитория; этот скилл — рабочая инструкция «как сопровождать».

## Как устроено (одной картинкой)

```
cron-job.org (каждые 10 мин) ──POST workflow_dispatch {"cron":"true"}──▶ GitHub Actions «Проверка билетов» (check.yml)
   │  (расписание GitHub в check.yml — только запасное: срабатывает пару раз в сутки)
   ▼
runner в США ──Tailscale──▶ телефон Redmi Note 7 в России (exit node) ──▶ ticket.rzd.ru   (иначе РЖД молчит)
             └─────────────────────────────────────────────────────────▶ api.travelpayouts.com (рейсы, раз в 30 мин)
   ▼
python -m dozor → события → Web Push на телефон (push/*.json) → коммит docs/data/*.json, state/state.json
   ▼
PWA на GitHub Pages: https://johnlennon000.github.io/bilet-dozor/
```

Ключевые файлы: `config.yaml` (что отслеживать), `.github/workflows/check.yml` (шаги запуска), `dozor/` (код), `docs/` (PWA), `docs/data/summary.json` (текущее состояние), `docs/data/probe.json` (отчёт probe), `state/state.json` (память сервиса).

## Посмотреть состояние

```bash
git fetch -q origin main
python3 .claude/skills/dozor-biletov/scripts/status.py      # наблюдения, события, источники (из origin/main)
```

Последние запуски и журнал — через GitHub MCP (`mcp__github__actions_list` с `resource_id: check.yml`, затем `list_workflow_jobs` и `get_job_logs` с `return_content: true`). Журнал доступен только после окончания запуска (до этого 404). Главные строки журнала:
- `устройство: Redmi Note 7 | в сети: да/нет | выход разрешён: да/нет` и `Страна выхода: RU` — телефон работает;
- `##[warning]Телефон не в сети…` — запросы пошли из США, РЖД ответит таймаутом;
- `WARNING train:…: Нет связи с источником (таймаут)` / `INFO [событие] …`.

## Типовые задачи

- **Запустить проверку сейчас**: `mcp__github__actions_run_trigger` → `run_workflow`, `workflow_id: check.yml`, `ref: main`, `inputs: {"probe": true}` (с отчётом в `docs/data/probe.json`) или `{"cron": true}` (обычная плановая). Без `cron` ручной запуск идёт с `--force` (рейсы проверяются вне очереди). Через 1–3 минуты ждать новый коммит «Данные …» в `origin/main`.
- **Поменять дату/станции основного поезда или рейсов** — правка `config.yaml` (`train.dates`, `flights.dates`, …). Смена маршрута сбрасывает «сообщённые цены» этого наблюдения — это нормально.
- **Временная проверка другого поезда** — блок `extra_trains` в `config.yaml` (пример там закомментирован):
  ```yaml
  extra_trains:
    - label: эксперимент
      from: Москва
      to: Сакмарская
      dates: ["2026-12-29"]
  ```
  Своя карточка, свои уведомления (в заголовке — маршрут). Москва всегда ищется как город (все вокзалы). Убрать — удалить или закомментировать блок; карточка исчезнет после ближайшего запуска (старые записи журнала событий остаются).
- После правок: `pip install pytest` (если нет) и `python -m pytest -q` (≈91 тест, 5 с), коммит с понятным русским сообщением, `git push origin HEAD:main` (пользователь разрешил коммитить в `main`). Пуш `config.yaml` или `push/**` сам запускает проверку.
- Изменили `docs/app.js`/`style.css` — поднять версию кэша `CACHE` в `docs/sw.js`, иначе телефон покажет старое.

## Диагностика по симптомам

Подробно — `references/troubleshooting.md`. Кратко:

| Симптом | Причина | Что делать |
|---|---|---|
| «⚠️ Не могу проверить билеты РЖД», таймаут | телефон выпал из Tailscale (в журнале «в сети: нет») | на Redmi: интернет, Tailscale → Connected, Exit node → Run as exit node; MIUI: «Нет ограничений», автозапуск |
| `SSLError` к РЖД | нет УЦ Минцифры | шаг «Доверять УЦ Минцифры» в check.yml и `certs/russian_trusted_root_ca.pem`; `verify=False` — никогда |
| в cron-job.org «401 Unauthorized» | неверный заголовок `Authorization: Bearer github_pat_…` или токен истёк | исправить/выпустить новый fine-grained токен (только bilet-dozor, Actions: Read and write) |
| в cron-job.org 500/502 | сбой API GitHub | ничего: пропал один запуск |
| «последний успешный ответ» не меняется 20–30 мин | отметка обновляется раз в 30 мин, «Обновлено» — раз в 15 | норма; проверки идут каждые 10 мин |
| запуск падает на «Сохранить данные» | гонка коммитов | уже решено (`ref: github.ref_name`, `rebase -X theirs`); если повторится — смотреть журнал |
| пуш не приходит | нет файла в `push/`, сменился ключ VAPID | приложение → «Включить уведомления» → «Открыть GitHub» → «Commit changes» |

## Внешние части, которые живут вне репозитория

- **Tailscale**: tailnet `johnlennon000.github`, телефон «Redmi Note 7» (с 7.11.2026 на кастомной AOSP-прошивке вместо MIUI; в консоли `redmi-note-7`) — exit node. После переустановки Tailscale устройство появляется заново: в консоли ⋯ → Edit route settings → Use as exit node, старую запись удалить; секрет `TS_AUTHKEY` (reusable+ephemeral, выпущен 4.11.2026 на 90 дней → **истекает около 2 февраля 2027**). Вход по authkey помечен в Actions как устаревший — работает, на OAuth-клиент можно перейти позже.
- **cron-job.org**: задание «Дозор билетов», каждые 10 минут, POST `https://api.github.com/repos/JohnLennon000/bilet-dozor/actions/workflows/check.yml/dispatches`, заголовки `Authorization: Bearer <токен>`, `Accept: application/vnd.github+json`, `X-GitHub-Api-Version: 2022-11-28`, тело `{"ref":"main","inputs":{"cron":"true"}}`. Токен GitHub — срок выбирал пользователь; напомнить продлить до 10 января.
- **Секреты GitHub**: `TRAVELPAYOUTS_TOKEN` (рейсы), `TS_AUTHKEY`; `PUSH_SECRET` не задан (ключ push выводится из токена — не менять токен без нужды, иначе подписку придётся переоформить).

## Нельзя

- Подключать Туту как источник без явного решения пользователя (внутренний API, протокол описан в `CLAUDE.md`).
- Предлагать соседние станции посадки (Уфа, Белебей) — пользователь отказался.
- Писать секреты в репозиторий; отключать проверку сертификатов.
- Добавлять в `state`/`summary`/`history` поля, меняющиеся каждый запуск (лишние коммиты; стережёт `test_identical_rerun_changes_no_files`).
- Ручной `python -m dozor` на копии репозитория с папкой `push/` — уйдёт настоящий push на телефон. В копии удалять `push/`.
- Смешивать с проектом ski-tickets того же автора.
